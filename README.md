# السيدة رزقي — مشروع أندرويد

نسخة محلية تعمل دون إنترنت، بواجهة عربية بنية وذهبية. التطبيق غلاف Android Java لواجهة HTML/CSS/JavaScript محلية داخل WebView، وليس تطبيق Jetpack Compose.

## المزايا
ثماني وصفات تجريبية، بحث وتصنيفات، مفضلة، مكونات وخطوات، وضع تحضير متدرج، مشتريات، إضافة وتعديل وحذف الوصفات، نسخ احتياطي نصي واستعادة. لا تسجيل دخول ولا خادم ولا فيديوهات ولا مزامنة أجهزة. الرسومات رموز وليست صور أطباق فوتوغرافية.

## من الهاتف إلى APK
1. فكّي ضغط المشروع باستخدام مدير الملفات.
2. افتحي github.com في المتصفح بوضع سطح المكتب وسجّلي الدخول.
3. أنشئي مستودعًا باسم sayida-rozqi وفعّلي خيار إضافة README أثناء الإنشاء.
4. عبر Add file > Upload files ارفعي محتويات مجلد المشروع وليس ملف ZIP، بحيث يظهر settings.gradle ومجلد app في جذر المستودع.
5. إذا تعذر رفع المجلدات من الهاتف، أنشئي الملفات في GitHub باستخدام Add file > Create new file مع كتابة المسار الكامل. الملف المهم هو .github/workflows/android.yml، وقد تخفيه بعض تطبيقات فك الضغط لأنه يبدأ بنقطة.
6. افتحي Actions، اختاري Build Android APK ثم Run workflow. أول دفع إلى main أو master يشغله أيضًا إن رُفع ملف سير العمل.
7. انتظري علامة النجاح، افتحي تشغيل البناء ثم Artifacts ثم Sayida-Rozqi-APK. يجب تسجيل الدخول لتنزيله.
8. فكّي ملف الـ artifact وثبتي app-debug.apk مع السماح بالتثبيت من هذا المصدر عند طلب أندرويد.

لا ترفعي ملف ZIP وحده: GitHub لا يفكّه تلقائيًا. لا تضعي المشروع داخل مجلد إضافي في المستودع. إذا لم تظهر Actions فتحققي من المسار الدقيق لملف سير العمل.

## البناء
AGP 8.9.0 + Gradle 8.11.1 + JDK 17 + Android SDK 35. سير العمل يثبت Gradle فلا يحتاج Gradle Wrapper. محليًا مع SDK وGradle المناسبين: gradle assembleDebug.
الملف الناتج app/build/outputs/apk/debug/app-debug.apk. هذا APK تجريبي موقع تلقائيًا بمفتاح debug، وليس إصدار متجر. قد يتغير مفتاح debug بين عمليات CI فتحتاجين إزالة النسخة السابقة، لذا خذي نسخة احتياطية قبل ذلك. للإنتاج يلزم إعداد مفتاح توقيع ثابت وحفظه في GitHub Secrets وتكوين release وAAB، ومراجعة سياسة الخصوصية ومتطلبات المتجر.

## تعديل المحتوى
المصدر المستخدم فعليًا هو مصفوفة initial داخل app/src/main/assets/index.html. ملف recipes.json نسخة مرجعية فقط ولا تقرؤه الواجهة تلقائيًا. التعديلات داخل التطبيق محلية ولا تُرفع إلى GitHub. احفظي النسخة الاحتياطية بنسخ نص JSON من شاشة وصفاتي إلى ملاحظة آمنة. لا توجد حماية أدمن: أي مستخدم للهاتف يستطيع فتح محرر الوصفات.

## الخصوصية والحدود
لا صلاحية إنترنت ولا تتبع ولا قاعدة بيانات سحابية. localStorage يحفظ البيانات في WebView، وإزالة التطبيق تمسحها. لا تدخلِي بيانات حساسة في النسخة الاحتياطية. التصميم مستوحى من درجات ألوان المرجع وليس نسخة مطابقة، ولا يتضمن الشعار أو صور المرجع الأصلية.

## حالة الاختبار
تم إعداد ملفات المصدر وسير البناء وفحص بنية الملفات فقط. لم يُنفذ Gradle أو اختبار على جهاز داخل بيئة إعداد المشروع. نجاح البناء والتوافق الفعلي يحتاج تشغيل GitHub Actions ثم تجربة APK.
